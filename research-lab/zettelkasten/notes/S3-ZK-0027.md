# S3-ZK-0027 — Lowering should be information-lossless with respect to facts later optimization still needs

TYPE: BRIDGE
STATUS: OPEN

## Thesis

A lowering phase need not preserve every source detail, but it should remain information-lossless with respect to the equivalence classes/facts required by downstream optimization and correctness.

## Source basis

Kohavi/Jha develops formal tests for information-losslessness in finite machines. Cover/Thomas gives a separate information-theoretic data-processing perspective: once relevant information is irreversibly discarded by processing, downstream stages cannot reconstruct it without side information.

## S3 inference

For each compiler boundary define a required-information contract:

```text
BOUNDARY: SSA -> Assembly IR
MUST_RETAIN:
  logical value equivalence
  type/representation constraints
  provenance-sensitive facts
  cross-block liveness identity
MAY_DISCARD:
  source syntax details not consumed later
```

Then test whether current lowering destroys required facts prematurely.
