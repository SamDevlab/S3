# S3-ZK-0018 — Search for a cost-optimal ternary operation basis

TYPE: HYPOTHESIS
STATUS: OPEN

## Thesis

The optimal internal ternary instruction set need not mirror the surface operators. A small functionally useful basis may permit cheaper lowering while preserving ternary semantics.

## Source basis

Gottwald treats truth-degree functions, families of connectives and functional completeness as central properties of finite many-valued systems. Babu presents concrete ternary AND/NAND/OR/NOR/XOR/XNOR and ternary processor components.

## S3 inference

For the finite trit domain, enumerate candidate primitive operation sets and synthesize other truth functions. Score each basis by backend cost:

```text
instruction count
+ conversions
+ branches
+ register pressure
+ packing/unpacking
+ code size
```

A basis may differ by backend/representation.

## Experiment

Build an exhaustive truth-table enumerator over 3-valued unary/binary functions, search generating bases under bounded expression depth, then compare generated x86 cost against direct lowering.
