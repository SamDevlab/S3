# S3-ZK-0021 — Measure compiler information loss, not only emitted instructions

TYPE: HYPOTHESIS
STATUS: OPEN

## Thesis

A compiler phase can be evaluated by how much useful decision information it destroys for downstream phases, not only by its immediate instruction output.

## Source basis

Cover/Thomas formalizes entropy, mutual information and the data-processing viewpoint: processing cannot manufacture information about an upstream variable that was already discarded. Kohavi/Jha separately studies information-lossless machines.

## S3 inference

Do not equate Shannon entropy directly with compiler quality. Instead use information theory as inspiration for measurable diagnostics such as:

```text
candidate representations before/after phase
value equivalence classes retained
location choices retained
proof facts retained
recoverability of logical identity
```

Possible experimental metric:

```text
FLEXIBILITY_LOSS(phase, value)
```

with Shannon-style quantities used only when a meaningful probability model exists.

## Guardrail

Do not manufacture an entropy number from arbitrary compiler states. A probabilistic/information-theoretic metric must have a defined random variable and interpretation; otherwise use deterministic cardinality/partial-order metrics.
