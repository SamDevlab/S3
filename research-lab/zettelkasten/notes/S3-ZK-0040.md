# S3-ZK-0040 - Memory reset byte weighting squares object length

## Claim

When one `rep stosb` reset event represents an initialization metadata array of
length `n`, the metadata-byte execution weight is `n * n` when the event itself
is observed once per object execution and its length is the per-event weight.

## Evidence

The corrected JSMN closure trace changed the memory reset total from an
under-counted object-length sum to the authoritative 14367-byte population.
