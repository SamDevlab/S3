# S3-ZK-0020 — Partition information can lower-bound state dependencies

TYPE: BRIDGE
STATUS: OPEN

## Thesis

Partition/refinement structure can express the minimum state information required to compute future state, providing a possible lower bound for compiler state/value dependencies.

## Source basis

Kohavi/Jha develops partition pairs, closed partitions and an information-flow inequality that characterizes how much present-state information is needed to determine next-state variables.

## S3 inference

For finite compiler state domains (especially trit/state-machine lowering), derive partitions induced by future observations. If a coarser partition suffices, preserving a more detailed physical state may be unnecessary; if a finer partition is required, an optimization that collapses those states is unsound.
