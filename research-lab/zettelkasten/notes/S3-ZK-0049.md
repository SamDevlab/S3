# S3-ZK-0049 - A branch-consumed comparison result is conditionally accidental

## Claim

A `TCMP` result is not globally dead merely because a `TBR3` follows it. It is
conditionally accidental when the branch is adjacent, consumes the same
destination, and liveness proves there is no successor observer.

## Evidence

On the fresh 15-workload O1 corpus, 566 static `TCMP` instances were followed
immediately by matching `TBR3` instructions and had no later result use. The
hosted emulator executed 66 such pairs. A successor `TRET` probe retained the
materializing fallback.

## Consequence

The sound production boundary is a local emitter fusion with an explicit
liveness proof. Assembly IR remains unchanged; the emitter chooses a direct
integer or ordered f64 branch only for the proven dead-result shape.
