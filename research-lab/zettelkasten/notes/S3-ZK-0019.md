# S3-ZK-0019 — Minimize semantic control states before binary branch lowering

TYPE: HYPOTHESIS
STATUS: OPEN

## Thesis

Control structures that naturally encode finite or ternary state should be simplified at the semantic/state-machine level before being committed to binary branch sequences.

## Source basis

Hopcroft/Motwani/Ullman develops state equivalence and minimization of finite automata. Kohavi/Jha studies state equivalence, minimization, state assignment, partitions and decomposition of sequential machines.

## S3 inference

For suitable compiler-generated state machines:

```text
semantic states
  -> equivalence/refinement
  -> minimized state machine
  -> state representation selection
  -> x86 branch/table lowering
```

This may reduce branches, duplicated blocks, state updates and representation conversions.

## Safety boundary

Only states proven observationally equivalent may merge. Failure/checked-arithmetic/reference side effects remain observable and prohibit unsafe equivalence.
