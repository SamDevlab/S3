# S3-ZK-0017 — Representation flexibility generalizes location flexibility

TYPE: BRIDGE
STATUS: OPEN

## Thesis

`LOCATION_FLEXIBILITY` is only one dimension of a more general compiler property: `REPRESENTATION_FLEXIBILITY`.

A logical value may have several valid realizations with different costs while retaining identical semantics.

```text
LogicalValue
  -> {GPR, frame, rematerialized, packed, canonical scalar, vector mask, ...}
```

## Source basis

Many-valued logic admits different truth-degree structures and connectives; multiple-valued computing realizes ternary behavior in different substrates; information theory provides tools for reasoning about descriptions/encodings without identifying information with one representation.

## S3 inference

Track a set of legal realizations and delay irreversible collapse until constraints force it. Register allocation then becomes one consumer of representation choices rather than the sole optimization problem.
