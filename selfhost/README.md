# Implementação autohospedada

Este diretório está reservado ao futuro compilador, assembler, runtime e
biblioteca padrão escritos em S3. Nenhum componente Python do bootstrap deve
ser tratado como parte deste núcleo.

O marco de funções e controle de fluxo já está especificado e validado. A
implementação autohospedada continua adiada até que memória e agregados mínimos
permitam representar fontes, tokens e estruturas do compilador. `spec/` e os
testes diferenciais serão o contrato de compatibilidade.
