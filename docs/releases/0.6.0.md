# S3 0.6.0

Status: validação de lançamento concluída. A tag e a release ainda não foram
publicadas.

## Destaques

- sintaxe fonte V0.6 como default;
- blocos estruturados por indentação;
- declarações postfix e mutabilidade explícita;
- controle ternário com `match`;
- arrays estáticos, leitura e atribuição indexada;
- diagnósticos hospedados em texto e JSON;
- backend experimental Linux x86-64 e ELF independente de Python;
- corpus oficial migrado para V0.6.

## Compatibilidade

V0.5 permanece disponível com `--source-syntax 0.5`. Não existe autodetecção,
fallback ou migração automática. A versão da distribuição `s3-bootstrap` é
0.6.0, mas os formatos IR JSON e S3 Assembly permanecem em 0.5.0; o schema
`s3-diagnostic` permanece em 1.0.0.

## Limitações

O único target nativo é Linux x86-64. O MVP não inclui heap, ponteiros,
módulos, strings, I/O da linguagem, ABI C pública ou self-hosting.

## Migração

Consulte o [guia de migração da fonte V0.5 para V0.6](../migration-source-0.5-to-0.6.md).
