# S3 0.7.0

Status: publicada em 5 de julho de 2026. A tag anotada v0.7.0 e a GitHub Release S3 0.7.0 foram publicadas. O Marco 0.7 está encerrado.

## Destaques

- limite de instruções hospedado e nativo;
- default compartilhado de 100000 instruções;
- CLI nativa e APIs configuráveis;
- instrumentação e limite real isolado em Linux x86-64;
- falha controlada antes do opcode excedente;
- diagnósticos estruturados e textuais completos;
- validação ELF real O0/O1.

## Compatibilidade

- sintaxe fonte continua 0.6;
- V0.5 permanece disponível por seleção explícita, sem fallback;
- formatos IR JSON e S3 Assembly continuam 0.5.0;
- schema diagnóstico 1.0.0;
- sem migração de fonte ou artefato;
- programas intencionalmente longos podem exigir limite explícito maior na CLI.

## Comandos

Os comandos suportam a opção `--max-instructions`:

```bash
s3 run programa.s3 --max-instructions 200000
s3 native-asm programa.s3 --max-instructions 200000
s3 build programa.s3 --max-instructions 200000
s3 run-native programa.s3 --max-instructions 200000
```

## Limites

- instrumentação ELF restrita ao target nativo Linux x86-64 apenas;
- a faixa nativa utiliza um inteiro `u64` indo até `2**64 - 1` na CPU;
- a contagem reflete as instruções baseadas no S3 Assembly executado após O0 ou O1;
- orçamentos artificialmente baixos podem atingir sites de falha diferentes entre O0 e O1;
- helpers físicos x86-64 não incrementam o contador;
- não é limite de tempo decorrido, de memória física alocada ou syscalls.

## Migração

Não há alteração de sintaxe, formato IR ou gramática; por isso, não há guia de migração de fonte.
Usuários de execução nativa longa podem precisar passar `--max-instructions` explicitamente, pois o default nativo agora é finito. Nenhuma alteração no código fonte S3 é necessária.
