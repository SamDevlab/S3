# ADR-0033: Deterministic Build Graph and Local Lockfile

Status: Accepted

## Decision

M1.45 adds a local-only build graph loaded from `s3.toml`. The graph contains
named S3 units, relative source roots, local path dependencies, explicit
foreign-library declarations, and a target/profile record. Unit dependencies
are resolved with a lexical tie-breaker and emitted in deterministic
dependency-first topological order.

The supported project target is resolved through the existing target catalog.
The profile records the compiler optimization level. Unsupported targets and
optimization levels are rejected before a build plan is produced.

The lock payload records source content hashes, unit paths and dependency
edges, foreign-library identity, target/profile data, topological order, graph
hash, per-unit artifact identities, and the overall artifact identity. It is
serialized as canonical indented JSON and can be written as `s3.lock.json`.
Absolute paths and paths escaping the project or unit root are rejected.

## Identity and isolation

The lock identity contains no machine-specific absolute path. It is based on
the normalized graph and source/foreign content bytes. A resolved graph
captures those hashes; loading sources later rejects a changed file instead of
silently building a different artifact. Per-unit artifact identities include
the identities of dependencies in topological order.

The build graph only loads local files and returns a deterministic source
collection for the existing compiler pipeline. It does not fetch Git or
registry dependencies, perform incremental compiler caching, or grant foreign
library access implicitly.

## Rejection policy

Missing units, sources, dependencies, or declared foreign libraries fail with
specific `BuildGraphError` diagnostics. Cycles fail before a build plan is
returned. A foreign library must be declared in the manifest before a unit
can reference it, and its target/kind/path are part of the lock identity.

## Consequences

Two equivalent project trees produce byte-identical lockfiles and artifact
identities. The hosted compiler can compare the graph's source collection with
an independent manifest calculation, and the Linux x86-64 backend can compile
the same multi-unit order. Public package distribution, semantic-version
resolution, remote fetch, and incremental compiler internals remain outside
M1.45.
