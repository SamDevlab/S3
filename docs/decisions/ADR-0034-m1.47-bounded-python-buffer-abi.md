# ADR-0034: M1.47 Bounded Python Buffer ABI

M1.47 uses the Python Stable ABI buffer protocol as a call-scoped consumer.
S3 owns its memory; Python never receives ownership and may not retain an S3
view. Views are one-dimensional, byte-format, C-contiguous, and explicitly
read-only or writable. Reallocation while a view is active is forbidden.
There are no callbacks, threads, or GIL handoff semantics.
