# ADR-0036: M1.49 WASI Preview 1 Core-Module Target

## Decision

M1.49 targets a core WebAssembly module using the `wasi_snapshot_preview1`
interface. The internal target identity is `wasm32-wasip1-s3`; it is not a
general public ABI promise until a later promotion decision. The artifact is a
`.wasm` core module, not a Component Model component.

Wasmtime is the certification runtime, pinned by exact release and recorded
with its checksum by the provisioning campaign. `wasm-tools` is the validation
tool, likewise pinned before provisioning. The S3 compiler owns encoding and
must emit canonical section/order choices; the runtime does not participate in
artifact identity.

S3 values cross the module boundary only through explicit i32/i64/f64 values,
or offset/length descriptors in linear memory. S3 owns guest memory. The
initial descriptor is `{offset:i32,length:i32,capacity:i32}`; offsets are not
source pointers and are never exposed as S3 raw pointers. Text is UTF-8.

Only declared CLI, environment, filesystem, and M1.48 TCP capabilities are
mapped. Ambient WASI imports, clocks, randomness, process spawning, UDP, and
DNS are forbidden. M1.48 networking is mapped only if the selected runtime
provider can expose the same bounded TCP contract; otherwise it is explicitly
unsupported in M1.49.

The logical S3 instruction limit of 100000 remains normative. Runtime fuel or
epoch interruption may be an additional safety limit, never a replacement.
The M1.46 test-runner timeout is the outer test authority; provider timeouts
remain operation-level limits.

This decision intentionally chooses the older, narrower core-module boundary:
the current S3 IR has no component type/lift/lower model, and M1.49 must not
invent one. Component Model support is deferred.

## Evidence

- WebAssembly core specifications define module semantics independently of an
  embedding: https://webassembly.org/specs/.
- WASI documents Preview 1 as the widely used `wasi_snapshot_preview1` API and
  Preview 2 as a distinct modular/component direction:
  https://github.com/WebAssembly/WASI.
- Wasmtime documents its Preview 1 bindings and CLI:
  https://docs.wasmtime.dev/api/wasmtime_wasi/p1/index.html and
  https://docs.wasmtime.dev/cli.html.
