# ADR-0029: M1.41 Deterministic Maps and Sets

Status: Accepted

## Context

M1.40 added closed ordered vectors while preserving the M1.39 ownership,
borrowing, allocator, and private-descriptor model. S3 now needs associative
and membership collections without introducing public generics, randomized
hashing, implicit growth, or a second ownership system.

## Decision

M1.41 adds two closed source types:

    i64_map
    i64_set

`i64_map` stores signed i64 key/value pairs. `i64_set` stores signed i64
values. Both preserve insertion order and use deterministic linear lookup.
There is no public generic collection syntax and no observable address or
hash identity.

Map insertion of an existing key replaces its value without changing order.
Removing an entry compacts later entries toward the front. Adding a duplicate
set value is a no-op. Removing an absent key or set value is a no-op.

Capacity is an exact element count. Construction and reserve are explicit;
put/add never grow implicitly. The hosted implementation uses the M1.39
allocator and move-only owner contract. Clone is an explicit deep copy that
preserves capacity. Shared and mutable borrows follow the established dynamic
buffer rules.

The physical native descriptor remains private. Map entries occupy 16 bytes
per element as `(key, value)` and set entries occupy 8 bytes per element. The
runtime stores byte length and byte capacity and derives logical element
counts from the closed operation family.

## Failure policy

Capacity arithmetic, allocation, full-collection, and index failures use the
existing deterministic runtime traps. An absent map get and an out-of-range
key/value/set index trap with bounds. Contains returns true as `-1` and false
as `0`, matching the existing trit convention. Move-after-use and borrow
conflicts remain semantic diagnostics.

## Alternatives

| Option | Determinism | M1.39 fit | Generic dependence | Decision |
| --- | ---: | ---: | ---: | --- |
| A. Closed ordered i64 map/set | 5 | 5 | 5 | Selected |
| B. Public `Map<K,V>` and `Set<T>` | 4 | 3 | 1 | Rejected by generics firewall |
| C. Hash-based opaque containers | 2 | 3 | 5 | Rejected: ordering and hashing are not stable |

## Boundary

M1.41 owns closed deterministic i64 maps and sets, explicit capacity, stable
insertion order, and native/hosted equivalence. Structured result/error
values, richer key domains, iterators with independent lifetimes, nested
owners, and general parametric collections remain outside this milestone.
