# ADR-0032: M1.45 Local Build Graph and Lockfile

M1.45 uses only canonical local path dependencies. Lockfile version is 1;
identity hashes are SHA-256 over domain-separated canonical UTF-8 records.
Paths, node IDs, target/profile IDs, dependency order, cycle errors, missing
dependency errors, foreign-library declarations, and explicit lock updates
follow `reports/future-architecture/M145_ARCHITECTURE_PREFLIGHT.md`.

Registries, remote resolution, and implicit cache identity are out of scope.
