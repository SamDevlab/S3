# ADR-0033: M1.46 Reproducible S3 Test Runner

M1.46 adds a convention-based runner over the locked project graph. It adds
no test language. Discovery and ordering are deterministic; timeout is in
milliseconds with a 10,000 ms default; hosted execution is semantic authority
and Linux native execution is a differential gate. Reports are versioned and
exit status is nonzero for failures, timeouts, resource failures, or runner
infrastructure failures.
