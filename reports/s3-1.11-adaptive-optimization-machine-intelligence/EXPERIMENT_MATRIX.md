No row is a compiler optimization promotion. The original architecture probe
is closed with `MACHINE_IR_NOT_JUSTIFIED_BY_CURRENT_EVIDENCE`, not presumed
success: the tested transformations were expressible in existing layers.
New rows must pin source SHA, workload and protocol before reporting results.

The edge-profile `002` report records exact counts only for a top-20 hot-block
subset where `TJMP` has one successor. It deliberately leaves all 93 reported
`TBR3` conditional edges unknown; destination block-entry counts are not edge
counts. The hot-fallthrough prototype uses one eligible 168-execution edge in
the energy workload. It removes one static branch/instruction and two `.text`
bytes, but the 21-pair timing interval remains inside the predeclared ±5%
materiality band. Independent Bench replay reproduced correctness and native
structure on the exact artifacts; this is not evidence of a general runtime
benefit.

The address-recurrence JSON is source-pinned to the exact point-cloud input;
its source diff is embedded so the two-site candidate can be reproduced. It
worsens every reported static native dimension except pressure counts, while
timing is too noisy to support a runtime claim. The candidate is rejected as
a structural transform for this workload.

The final value-cost executor is pinned by its `experiment_tool_sha256` in
the final JSON artifacts. `EXP-S3-111-VALUE-COST-001-run2.json` preserves
the earlier 21-sample-per-workload timing run; `...001-final.json` is a
separate run validating the final Pareto output schema. The tool applies the
same guard to `EXP-S3-111-VALUE-COST-002`. None of these changes are wired
into production.
