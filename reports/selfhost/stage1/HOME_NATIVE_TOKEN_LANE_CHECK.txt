S3 PR #268 — PRE-IR-v2 WIDE TOKEN LANE NATIVE CHECK
=====================================================

Purpose
-------
The prior compaction chain is no longer authoritative as the first native gate.
The frozen Stage1 packs token values as:

    next_cursor*1000000 + kind*1000 + value + 500

so numeric values outside [-500,499] spill into neighboring fields. Native/static
evidence already identified PACKED_TOKEN_VALUE_LANE_OVERFLOW. Before any further
IR-v2 compaction/parameter/local work, qualify the candidate that packs numeric
zero and reconstructs the exact signed i64 value from the source range.

Expected useful output
----------------------

The pre-chain should report:

    STATIC_FULL_COVERAGE=True
    NATIVE_TOKEN_LANE=<PASS_NATIVE_CANDIDATE or factual blocker>
    FULL_SOURCE_CALLS=<measured/static exact requirement>
    FULL_SOURCE_CALL_ARGUMENTS=<exact requirement>

A token-lane native PASS does not mean capacities pass. It proves the scanner can
observe the complete self-source. Newly exposed call/event/value/block capacity
requirements are expected to become the next engineering input.
