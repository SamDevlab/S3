LOCAL METADATA
The local candidate preserves:
- owner function ID;
- name identity;
- type ID;
- mutability;
- storage kind (SCALAR or FIXED_ARRAY);
- per-function local ordinal;
- fixed-array extent;
- semantic value ID.

Physical frame/byte offsets are not frozen in semantic IR. The future emitter owns deterministic physical layout.

Historical local_count=23 is not used as capacity authority. The fresh parameter candidate must agree with the Stage1 lexical/hash model for local/value/event/call counts before local native qualification.

Local record capacity is selected from the exact self-source candidate requirement. A single lane is allowed only when required_records <= 365; otherwise the chain routes to measured banked-local storage.
