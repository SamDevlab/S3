# S3 1.2 Self-Host Compiler Substrate

## Scope

This increment adds the ordinary runtime substrate needed for future compiler
representability work: deterministic `map<text, i64>`, symbol interning,
indexed arenas, lexical environments, source transport, bounded output, and
transactional compiler-shaped state. It does not implement a lexer, parser,
semantic compiler, lowering, verifier, emitter, or Stage1 V4.
